# ⚡ NoobieKernelRE by NoobieThingZ

🚧 **Current Project** on branch [`RebornEdition`](https://github.com/itsmeleju/NoobieKernelRE/tree/RebornEdition)

I’m currently working on ✨ **NoobieKernelRE** ✨ — a custom kernel focused on:

* 🚀 **Performance**
* 🧊 **eBPF 5.10 Integration & Optimizations**
* 🔋 **Battery Efficiency & Thermal Control**

> 💡 Built with a balance of stability + smoothness + power efficiency. The successor to the original, now deprecated *NoobieKernel*.

---

### 🌙 Status

* 🛠️ **Actively in development**
* 🧬 Based on **Aigis-Kernel-A32** by [@SlamZDank](https://github.com/SlamZDank)
* 🥀 *NoobieKernel is officially archived and deprecated.*
